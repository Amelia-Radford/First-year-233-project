# First-year-233-project
## Notes on File Paths
This project originally ran in a browser-based IDE used for course submission. 
In that environment, file paths were handled automatically.

When running locally in VS Code, the program requires hardcoded absolute paths 
to access input files. Because of this, the current version will not run 
without adjusting the file paths to match the user's system.

The logic and structure of the program are correct; the only limitation is 
environment-specific file handling.
